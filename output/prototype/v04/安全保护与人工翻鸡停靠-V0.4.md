# 安全保护与人工翻鸡停靠 V0.4

日期：2026-11-03。范围：离线原型计算与控制需求。所有停车性能是假设输入，不是SO-101实测能力；本文不授权热态运行或人员进入。

## 结果与变化

1. V0.3的17.4秒路线满足运动学和粗碰撞筛查，但不能据此证明故障停车安全。加入反应延迟、朝障碍方向的初始加速度、制动加加速度和误差预算后，需要进一步减速。
2. 在本报告假设下，得到46.8秒/勺的条件性参考路线；它不是硬件必须达到的最终节奏，也不是已经验证的安全速度。实测停车性能、增大净空或改工具/安装位，可重新计算。
3. 选定锅左近侧泊位：勺口中心(-240,-300,195)mm。从锅内高位点出发，包含倒回锅内的完整参考流程35.4秒；已经倒空时可跳过前段，以20.2秒退出停靠。
4. 泊位姿态的整臂/工具粗包络位于半径250mm操作空间之外，最小径向余量约61.8mm。该圆柱仅为空间假设，不是人体防护安全距离。
5. 必须有独立机械支撑与锁止，且驱动禁止、停稳、有效反馈等条件成立后才允许人工翻鸡。实际硬件尚未制造或验证，默认不允许进入。

## 采用的工况和坐标

延续前轮工况：锅口400mm、深120mm；液位80mm；勺口50mm；鸡包络260×180×150mm，向远侧偏移50mm。底座(0,-400,80)mm，安装角90°；工具仍为80mm下垂、90mm伸出的假设弯颈结构。

原点在锅最低点，X沿鸡身长度方向，Y正方向远离机械臂，Z向上。所有坐标不是相对台面高度。

## 停车保护计算

### 假设输入

| 参数 | 试算值 | 必须怎样验证 |
|---|---:|---|
| 故障发现至开始有效制动的总延迟 | 100ms | 测本地检测、控制、总线和舵机的最坏总延迟，不能只测电脑循环 |
| 最低有效减速度 | 200mm/s² | 对所有相关部位/相对接近运动成立，不只是TCP |
| 制动加加速度幅值 | 1000mm/s³ | 本模型按该值完成减速度建立/撤除，须实测控制器和硬件响应 |
| 制动开始前向危险方向的加速度上界 | 50mm/s² | 包括反应期间；数值轨迹只做筛查，实机跟随误差另计 |
| 总相对位置不确定度 | 5mm | 校准、载荷挠曲、关节间隙、摆锅误差等的总预算，尚未证明 |
| 另留储备 | 5mm | 设计余量，不能替代未统计的不确定度 |

5mm不是编码器分辨率。多个关节的角度误差会通过臂长放大，应由实际TCP与连杆位置测量证明。单个关节1°在300mm力臂处就可产生约5.2mm位移。

### 模型

保护所需空间 = 反应期间前进量 + 受限加加速度制动距离 + 总相对位置不确定度 + 储备。

反应期间按正向加速度50mm/s²持续，先计算反应结束速度。随后用分段恒定加加速度建立负加速度、必要时保持、再撤除至零；解析积分到最终速度与加速度均为零。没有把原来的速度瞬间变成零，也没有假设制动开始时加速度一定为零。

### 结果

| 危险部位或两部件相对速度 | 所需保护空间，含10mm误差与储备 |
|---:|---:|
| 20mm/s | 约17.8mm |
| 40mm/s | 约26.5mm |
| 60mm/s | 约37.1mm |
| 80mm/s | 约49.8mm |
| 100mm/s | 约64.4mm |

在上述假设下，仅有15mm净空时，条件允许速度约12.5mm/s，而非80～100mm/s。若实测延迟更长或减速能力更弱，允许速度还要下降。

这些数值是机器人与固定障碍、或非相邻部件相互接近的空间预算，不是“人可以站在这个距离”的计算。没有包括人向机器人伸手的速度与人体可达范围，因此不能用本表代替人员隔离设计。

### 对原路线逐部位筛查

检查了连杆中心线点、半径带来的旋转速度上界、勺柄、勺体表面，以及前轮列入检查的非相邻部件对。相互接近时采用两部件速度/加速度上界之和，故意偏保守。未检查的原厂网格、附加零件、线缆和接触面仍然是缺口。

V0.3最明显的不足：空勺返回时，勺体速度约100mm/s，而距鸡包络仅约20.8mm；该条件下允许速度约27.3mm/s。肩部与前臂的相对运动也约束了抬勺阶段。

采用分段减速并加10%时间储备后，得到以下冷态参考：

| 工序 | 时间/s |
|---|---:|
| 取汁停留 | 0.7 |
| 竖直抬勺 | 12.2 |
| 高位平移 | 6.5 |
| 定点倾倒 | 4.0 |
| 等待滴流 | 0.7 |
| 恢复水平 | 4.0 |
| 空勺返回 | 6.5 |
| 下降取汁 | 12.2 |
| 合计 | 46.8 |

三条路线均通过当前假设下的数值空间预算筛查。该节奏偏慢，不能据此认为烹饪工艺有效。应优先实测停车能力、扩大碰撞净空、优化工具和安装位，不能为了达到原先周期而直接取消保护余量。

## 外部泊位和路线

| 点 | 勺口中心坐标/mm | 用途 |
|---|---|---|
| S | (0,-100,195) | 已验证的锅内高位接管点 |
| D | (0,-100,160) | 不确定剩余汁量时，将汁倒回近侧锅内 |
| G | (-140,-220,220) | 锅左近侧退出中转点 |
| U | (-240,-300,220) | 泊位正上方 |
| K | (-240,-300,195) | 概念落座点 |

完整路线：S→D→倾倒45°→滴流→恢复水平→S→G→U→K。

| 阶段 | 条件性参考时间/s |
|---|---:|
| 降至D | 3.3 |
| 倒回锅内 | 3.8 |
| 等待残汁滴流 | 1.0 |
| 恢复水平 | 3.8 |
| 回到S | 3.3 |
| S→G退出锅口 | 10.2 |
| G→U | 7.2 |
| U→K低速落座 | 2.8 |
| 合计 | 35.4 |

已经完成一勺并以空勺返回S时，省略倒回段，退出参考时间20.2秒。计时结束不代表锁止完成，也不允许据此放行人员。

退出路线最小粗包络额外净空约24.4mm，已经先扣除了7.5mm几何设计间隙；距离模型关节硬限位的最小余量约19.3°。前期G=(-100,-230,220)mm的方案仅余约1.7°关节限位空间，已排除并改为当前G点。

倾倒滴流的时间不证明勺子已空。D点落流、飞溅、剂量和残液尚未仿真，应以可能仍有一整勺汁的情况设计外部接液盘。发生异常时不要把满勺强行送往泊位。

返回采用K→U→G→S，条件参考20.2秒；必须在人工完成、区域清空、锅位和点位重新确认后开始。当前只验证了原鸡包络不变的路线，翻鸡后若翅腿或高度超出包络，必须更新模型和点位。

## 泊位机械结构需求

### 支撑、锁止与接液

- 主要支撑/锁止设在腕部或可靠承重支架，不能只用汤勺薄柄承受整臂作用。
- 模型中腕部参考位置约(-153,-322,275)mm，可作为设计金属托架的起点；按20mm近似包络，托架接触高度约255mm。真实接触面必须按实物设计。
- 采用断电仍保持的机械锁，例如弹簧施锁、动力释放的锁扣；应约束可能导致扫臂和翻勺的运动，不仅托住竖直重量。
- 可增加前臂支撑减轻腕部受力。支架、二次防脱和底座连接均须校核。
- 接液盘概念中心(-240,-300)，外形可先试120×120mm；内腔100×100mm、有效液深15mm提供约150mL容积，超过本轮33mL汁量的三倍。此为容积设计起点，不是飞溅防护验证。
- 盘底参考Z=140mm、盘沿Z=160mm，概念勺底停靠Z≈170mm。需要与实际勺体、弯颈、支架共同校核，并留清洗与拆卸空间。
- 受力、锁止与热汁频繁接触部位优先金属；打印件先用于冷态孔位和形状试配。

当前计算没有加入托架、锁扣、接液盘的完整实体碰撞及接触力学，因此“达到K点”不等于“实物能可靠落座”。落座还需低速接近、接触/落座确认及防夹手设计。

### 初步静载量级

按模型运动部分与工具合计约0.519kg，且保守保留33g汁液：

- 总重约5.09N。
- 将全部运动重量假设由腕部泊位接管，关于该支撑点的重力合矩约0.356N·m。
- 单纯按2.5倍静载作样件筛查，至少约12.7N竖向载荷和0.89N·m弯矩；可先以不低于15N和1N·m的静载工况检查原型。

这不是最终额定值。真实多支点反力、锁扣侧向受力、冲击、热蠕变和驱动意外施力尚未计算；不得据此选择一个“15N锁扣”就认为完成设计。锁止期间必须独立禁止驱动产生危险动作。运动途中失电时也尚未靠泊，因此外部泊位不能替代全程防坠落保护。

## 人工翻鸡流程和状态互锁

### 正常翻鸡请求

第一版采用零速边界接管，避免从任意高速姿态突然切换路线：

1. 操作人员按“请求翻鸡”，系统锁存请求，人员仍留在防护区外。该按钮不是急停。
2. 若正在取汁/抬勺：在已验证段内完成到S，然后走倒回与停靠路线。
3. 若正在移向鸡身、倾倒或恢复水平：完成当前一勺，返回S后取消下一次下降，直接停靠。
4. 若请求发生在已经开始下降之后：先在已验证路径到P，再抬到S；按可能带汁处理，倒回后停靠。
5. 到U后低速落座K，确认托架承重与机械锁闭合。
6. 确认全轴停稳、驱动禁止、反馈有效、支撑/锁止能力已验证，以及人员与机器人运动区有独立隔离，才进入人工翻鸡模式。

按当前慢速时序，最不利正常请求约需59.8秒到K，另加实际锁止和确认时间；这只是参考路线时间上界，不是安全超时或放行倒计时。自动计时工艺可提前请求退位，人工看护期间可自行调整火力。

如果出现人员提前进入、过流、失联、碰撞风险或位置不可信，应走故障停机；不能继续完成上述动作来“赶紧停到泊位”。

### 人工进入的必要条件

以下均为需求，不能由网页动画或普通程序变量冒充硬件证明：

- 独立保持/锁止方案已经验证；
- 实际位置位于泊位容差窗；
- 全轴停稳已确认；
- 托架确实落座；
- 机械锁闭合；
- 驱动禁止反馈成立；
- 所用反馈新鲜、有效；
- 无未处理故障；
- 独立的空间隔离已建立。

任一条件不成立或状态不可信，默认不放行。落座开关和锁闭开关应观察不同的物理条件；两个普通开关并不会自动成为经过验证的安全回路。

`access_logic.py`仅演示这些条件的默认拒绝逻辑，初始`independent_holding_validated=False`；没有连接真实I/O，不会授权现场人员进入。

### 人工完成后的恢复

人工确认完成 → 手和工具退出 → 恢复隔离 → 确认锅位、鸡包络和点位 → 显式按重新启动。

此时仍保持锁止和驱动禁止。先以读取到的实际角度接管，确认驱动能保持且不会跳动，再受控释放机械锁；垂直抬离托架至U，再经G返回S。不能先松锁再等待电机接管，也不能因关门或检测到手离开就自动重启。

如果实物支撑、制动和接管能力没有验证，初版仅能做冷态过程演示，不开放人工伸入自动运动区域的功能。

## 空间隔离的含义

半径250mm圆柱只是“锅口半径200mm＋周边50mm”的操作空间假设。停靠状态的粗包络在其外约61.8mm，并不证明人的手、手臂、长柄夹具或身体不会到达泊位。

建议把泊位放在锅左近侧，人工从右侧或远侧操作，避免手臂跨过机械臂和热勺；具体站位、翻鸡工具和全身可达空间需实际演练。托架、接液盘、热勺均要隔离于人工翻鸡路径。

原炉具继续人工控制。机器人停机或进入泊位不会自动关闭加热，这一版本不能用于无人看护。

## 实物验证清单

1. 测最坏控制反应时间、制动建立/撤除、重力方向影响和失电行为，替换本报告假设。
2. 测带汁载荷下的TCP与连杆位置误差，证明或扩大5mm不确定度预算。
3. 补托架、盘沿、锁扣、线缆和炉具网格，检查退出/返回/落座全过程；对接触过程单独验证。
4. 冷态验证满勺、部分残液、滴漏及盘容量；不要只按“已倒空”的名义测试。
5. 在接液、机械防护及现场控制条件下逐阶段验证暂停、失联、掉电、锁扣不到位、反馈过期和恢复接管。
6. 最后再验证热态变形、清洗、锁止耐久和实际烹饪节奏。

5000元预算若不足以完成独立保持和验证，应保留为冷态原型；外部停靠不是取消运动中防坠落的理由。
