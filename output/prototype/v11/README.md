# 机械臂浇汁工艺原型 V0.13

2026-11-03。局部可运行技术原型，不是完整首版。

## 启动

```sh
python3 output/prototype/v11/server.py --port 8765
```

打开`http://127.0.0.1:8765/`。依赖Python和NumPy；Three.js与模型均已本地保存，不需要启动时联网。仅监听本机。不要用`file://`直接打开index.html。

点击运行，默认流程执行舀汁、6段运动及保持倾角，共8个动作、48.6s动作时间。后端逐段求解IK、时间参数轨迹和简化碰撞检查，按20ms推进关节与液体，前端驱动正式网格。可暂停、继续、步进和取消；1×/4×/8×只改变推进速度，不改变dt。

`flow.py`提供可信默认流程，启动时转为版本化步骤。界面可编辑步骤JSON并保存新版本、导入导出；步骤生成只读Python代码视图，执行端直接解释已校验的动作，不eval/exec导入代码。任意Python隔离执行尚未建立。

## 自动验证

```sh
python3 -m unittest discover -s output/prototype/v11 -p 'test_*.py' -v
node output/prototype/v11/verify_browser.cjs
```

第二条需先运行本地服务，通过根目录`npm ci --ignore-scripts`安装锁定的Playwright，再安装其Chromium或用CHROME_PATH指定Chrome。优先使用常规项目依赖，开发环境可回退到现有运行库。WORKBENCH_URL可指定服务地址。为得到干净初始场景和事件计数，完整测试前重启服务。

浏览器使用软件WebGL进行链路测试，不用结果推导真实GPU性能。`evidence/`保留PNG、图像对应快照、动作事件和机器可读测试报告。

## 资源

SO-101来自官方仓库固定提交；Three.js固定r170。`assets/manifest.json`记录来源、哈希和字节数，两套上游许可文本一并保留。本机原有NumPy、Playwright和Chrome版本在验证报告中记录，不属于本次下载资产清单。

采用官方连杆/电机网格，移除原夹爪活动爪及夹爪驱动电机的显示，增加假设的弯柄汤勺；五个运动轴由原URDF驱动。工具沿用早期本地+X法向定义，显式记录于模型；迁移到详细设计建议的工具+Z法向时需固定旋转转换。

## 已知限制

- 固定S_BASE场景；有流程版本，但没有场景编辑、通用文件树/技能模块管理、控制租约或持久作业服务。
- 执行受支持的move_tcp/scoop/wait步骤；不代表CD08任意Python隔离要求已完成。
- 碰撞采用旧离线简化包络，非完整网格/连续碰撞。锅显示已与该球冠形近似统一；鸡外观和保守碰撞包络仍明确分开。
- 初始姿态直接加载为已校验的仿真起点，不声称执行过从任意姿态的初始化运动。
- 运行期间时钟独立于规划等待；action_tick记录动作步，tick还包含规划期间保持，实际模拟用时可大于48.6s。
- 液体为未标定近似：取汁几何条件、有限容量、倾角流出、弹道流束和表面回流；没有CFD、黏度/飞溅标定或热模型，温度/电流不可用。
- 已提供12个stdio MCP工具及独立截图工作进程，详见根目录MCP.md；无持久渲染队列，尚未验证特定桌面MCP宿主。
- 快照在内存中，最多6000帧；服务重启即清空。原型未实现请求周期内快照保留、跨重启幂等或故障恢复。
- 当前已显示模拟角、终点角、模拟速度及限位说明，提供±1°有限手动移动；尚无遥测趋势和连续点动租约。
- 取消当前原型会暂停整个会话，冻结液体；未来完整产品需将作业取消与会话暂停进一步分离。

后续设计改动见`../../design/v10/09-手动控制与MCP截图.md`；07/08保留历史实现记录。
