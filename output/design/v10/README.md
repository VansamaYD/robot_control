# 机械臂仿真工作台：详细设计 V1.0-draft

日期：2026-11-03。状态：第一轮详细设计，进入开发前的评审基线；不是已实现产品，也不是已验证的技术选型。

用户已确认的核心：纯仿真、代码管理与执行、运动可视化、MCP状态/动作/截图。下列具体实现由本轮提出，后续技术验证可以修改。

## 阅读顺序

1. `01-需求审查与验证报告.md`：检查结论、修正内容、未验证风险。
2. `02-架构与模块设计.md`：模块、进程、技术选型和依赖边界。
3. `03-执行引擎与代码设计.md`：时钟、技能、代码运行、调试和控制权。
4. `04-数据与接口设计.md`：数据契约、API、MCP、错误、截图。
5. `05-场景运动与液体设计.md`：模型、坐标、轨迹检查、液体收支。
6. `06-界面与实施设计.md`：交互、面板、开发顺序和验证门槛。
7. `07-链路验证结果与设计修订.md`：已运行原型证据、发现的问题和基于结果的架构修订；涉及冲突时以本轮修订为准。
8. `08-流程版本与液体闭环.md`：0.12已实现的流程版本、JSON编辑/导入导出、液体收支和独立时钟，以及未完成范围；覆盖07中的对应旧限制。
9. `09-手动控制与MCP截图.md`：0.13手动有限步进、遥测、真实MCP和截图工作进程，覆盖08中对应的未实现事项。
10. `10-液体故障修复与恢复停靠点动.md`：0.14用户问题复现、液体修正、回初态/显式重置、模拟翻鸡停靠和租约长按，覆盖09中的相关缺项。
11. `11-自然进液与近空离锅互锁.md`：0.15接触驱动进液、不经取汁位的无条件排汁互锁、规划计时和碰撞批量化，覆盖10中的对应旧行为。

配套`contracts/`包含可运行的控制状态语义参考及测试；它不执行机器人运动，不实现MCP、脚本隔离或物理仿真。运行方法见验证报告。

需求仍以`../../requirements/v07/README.md`所列有效集合为来源；本目录V1.0表示详细设计草案版本，不能解读为所有需求与技术方案已经冻结。
