# 06 界面与实施设计

## 工作区与面板

默认桌面1280×800验收基线：顶部约56px，左侧项目/场景树约220px，右侧代码约420px，下方状态区约220px，其余三维视图。均可拖动/收起；空间不足时使用“场景/代码”主视图切换，状态和取消入口仍可访问。精确尺寸是原型起点，不是固定屏幕要求。

| 区域 | 内容 | 主要交互 |
|---|---|---|
| 顶栏 | 项目/已保存版本、仿真或回放、会话健康、控制者、任务 | 保存并运行、暂停、取消、停靠；禁用项解释原因 |
| 左栏 | 文件树、流程入口、技能、场景对象与点位、版本记录 | 打开源码；选对象显示参数；另存/恢复版本 |
| 三维 | 正式模型、锅鸡勺液面、轨迹、TCP、碰撞包络 | 相机/对象编辑明确分模式，选点可示教；视图不修改权威状态 |
| 代码 | 语法/错误、调用位置、技能栈、步骤切换 | 参数化运行、动作/技能步进；不支持的逆向编辑只读说明 |
| 底栏 | 当前任务、关节表/趋势、液量、事件日志、时间轴 | 错误定位源码和物体；回放帧截图 |

关节表列：名称、ID、目标deg、模拟deg、误差deg、模拟deg/s、限位/质量。展开电气字段默认N/A及原因；不以0代替未知。液体栏显示P/L/A/C/S及守恒偏差和“未标定”标记。

## 关键页面流程

### 首次启动

启动服务 → UI健康检查 → 加载示例项目 → 资源/映射/场景检查进度 → 三维首帧 → 暂停就绪。渲染可用而代码运行器不可用时，分能力显示错误，不能以总绿灯掩盖。用户可手动观察，但完整首版仍未通过。

### 保存并运行代码

选择入口 → 填写Schema驱动参数 → 显示未保存修改 → 保存为新版本 → 校验报告（明确分支覆盖）→ 运行。运行栏固定版本号；修改源码时显示“影响下次运行”。控制忙时显示所有者及任务，可观察，不暗中强夺。

### 调试取汁

暂停 → 选择取汁点 → 显示勺口/法向/液位 → 下一动作 → 观察浸入和勺内量 → 下一技能完成取汁 → 切换代码定位调用。空锅或阻挡时显示真实失败原因，三维标注相应区域。

### 模拟翻鸡

请求停靠 → 进度显示余汁处理/退出/停靠 → waiting_operator → 进入鸡编辑模式 → 草稿姿态 → 应用检查 → 恢复报告 → 确认启动新阶段。确认按钮显示新配置和剩余轮次；路径失败时保持等待并允许修改，不提供“仍然执行”。

### 模型接入

连接页显示本地MCP启动配置、当前能力、最近工具调用/任务和图像帧。MCP启动的流程在同一代码/三维区域展示，模型与人看到相同run ID和快照。模型输出解释文本不当成执行成功凭据。

## 必须区分的状态

场景草稿与生效；保存版本与工作副本；运行与回放；请求受理与完成；暂停与等待操作者；仿真就绪与渲染就绪；模拟量与不可用电气量。颜色之外配文字/图标，错误可复制含request/job ID的诊断信息。

## 实施顺序与退出条件

| 阶段 | 产物 | 退出条件 |
|---|---|---|
| D0 契约与资产 | 本设计、资源清单、状态契约、测试夹具 | 文档检查及控制语义参考测试通过；正式模型来源/许可/哈希明确 |
| D1 三维运动纵向链路 | 正式URDF、关节/TCP移动、核心时钟、状态表、轨迹/碰撞 | 不同渲染FPS同tick状态一致；中途碰撞和不可达被拒绝 |
| D2 代码与版本 | 项目编辑、版本快照、技能、隔离SDK、暂停/取消 | 脚本驱动D1；死循环/越权/旧消息测试通过；不通过不得开放任意脚本 |
| D3 工艺闭环 | 取汁/倾倒/液面/账目、停靠、编辑鸡、新阶段 | 空取汁失败；守恒和恢复检查通过；两场景分别有报告 |
| D4 MCP/截图 | 真实客户端、相同作业服务、独立帧渲染 | 无UI仍可运行/查询/按指定快照截图；错误/重试不重复执行 |
| D5 完整验收 | 回放、导入导出、性能和使用说明 | 48组场景逐项有证据；101项有效条目无未说明缺口 |

每阶段保留可运行小样，D1不表示完整首版交付。若技术原型推翻方案，修改ADR和接口契约后再推进，不靠增加UI占位掩盖缺能力。

## 当前未冻结项

Python候选运行器的实际隔离/兼容性、精确依赖版本、首个MCP验收客户端、资产许可清单、性能设备与预算、碰撞采样阈值、液体流量近似参数。它们不阻止设计开展，但对应功能未经实测不能标为完成。无需新增账号/云平台或立即购买硬件来解决这些问题。
