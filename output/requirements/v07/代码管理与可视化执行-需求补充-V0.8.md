# 代码管理与可视化执行：需求补充 V0.8

日期：2026-11-03。需求草案，尚未实现。本文覆盖V0.7中的D06、PR09及相关范围描述；其余需求继续有效。

## 1. 已确认的调整

用户明确要求：步骤编辑器可以作为包装；系统必须管理可执行的流程代码，不同操作对应运动流程代码；执行代码后，可视化观察机械臂完整运动过程。

因此，首版加入代码项目管理、编辑、版本记录、执行与三维联动。取消“代码执行整体后置”的安排。编程语言尚未由用户指定，建议采用受限Python流程脚本，不因此承诺运行任意Python工程或安装任意第三方包。

首版仍为纯仿真，MCP状态、动作和截图接口仍为必需项。

## 2. 四层结构

1. 项目：流程源码、可编辑技能源码、场景与点位、参数、资源引用和版本记录。
2. 流程：如单轮浇汁、循环浇汁、停靠等待翻鸡，通过代码组合技能。
3. 技能：如取汁、定点浇汁、停靠；展开为有明确单位、前置条件和退出条件的动作。
4. 执行服务：求解运动、检查路径、处理控制权、推进仿真并输出状态。技能不能绕过此服务直接改变关节位置。

步骤编辑器与代码编辑器是同一项目的两种入口；三维画面根据执行服务的状态渲染，不能另播一段与代码执行无关的动画。

## 3. 首版代码管理范围

| ID | 优先级 | 要求 |
|---|---|---|
| CD01 | P0 | 项目列表与文件树；创建、打开、重命名、复制、保存、导入与导出项目；路径限制在项目目录 |
| CD02 | P0 | 内置代码编辑器：语法高亮、基本补全、错误定位；明确显示未保存修改 |
| CD03 | P0 | 项目包括流程入口、技能模块、场景/点位、默认参数与依赖清单；提供可运行示例 |

| CD05 | P0 | 新建/复制/编辑项目内技能；发布为新技能版本，显示参数、单位、前置条件和失败原因；不允许替换受保护的执行检查层 |
| CD06 | P0 | 代码预检查、启动、暂停、继续、单步、取消；当前代码位置/技能/动作与三维状态关联，显示执行栈和异常 |
| CD07 | P0 | 循环、条件和模块调用可用于流程；有执行时限、动作数和资源限额；纯计算死循环也可由宿主强制终止 |
| CD08 | P0 | 用户脚本在隔离运行器中执行，仅能通过授权SDK操作仿真；禁止访问宿主凭据、串口或绕过检查；仅独立进程不视为充分隔离 |
| CD09 | P0 | 界面、MCP共用项目版本和作业接口；MCP可列出版本、校验及运行指定入口、查询和取消；首版默认不提供任意源码写入工具 |
| CD10 | P0 | 导出运行记录包含源码/技能版本、场景版本、参数、种子、动作事件、错误和关联状态；支持复现与只读回放 |

## 4. 执行与可视化语义

- 代码调用SDK产生动作请求，经过参数检查、起始状态核对、轨迹检查和控制权检查后进入统一执行服务。
- 静态可展开流程可全程预览；依赖运行中状态的条件分支，只预检可确定部分，实际产生每个动作时再检查，不声称已完整验证未知未来分支。
- “单步”默认执行下一条机械臂动作；另提供推进一个仿真时间步。暂停时仿真时间冻结，单步执行后再次暂停。暂停在动作边界时与中途暂停明确区分。
- 源码行高亮表示所属调用位置；在该行等待的动作完成前不跳到下一行。嵌套调用展示流程与技能两层执行位置。精确任意Python语句调试器不是首版默认承诺。
- 编辑正在运行的文件只影响下一次启动；取消后旧运行器不能继续提交动作，重启也不能恢复旧队列。
- 脚本日志有速率限制；脚本崩溃、超时或运行器断开后，由独立宿主管理作业终止与队列失效，不能依赖脚本自己清理。
- 运行时条件使用一致的仿真状态快照和仿真时间；结果与输入/种子/版本一同记录。回放不重新执行旧控制命令。
- 轨迹预览、状态曲线与截图都引用同一运行ID和状态版本。

## 5. 建议项目结构

```text
soy-chicken/
  project.json
  flows/
    baste.py
    park_and_wait.py
  skills/
    scoop.py
    pour.py
  scenes/
    kitchen.json
  parameters/
    default.json
```

这是建议结构，不是已经实现的SDK。运行产物单独存放并引用不可变版本，不能覆盖流程源码。

## 7. 对计划的影响

M0补充SDK、代码版本与隔离运行器方案；M1保持三维与手动控制；M2增加代码项目、技能和运行联动；M3让MCP调用同一代码作业系统；M4加入上述验收。

原V0.6工作量估计不能直接当成此次扩大范围后的承诺。选定脚本运行方式、支持语法和隔离边界后重新估算。优先交付少量端到端可运行的示例技能，避免先建设大而空的代码平台。
